# HUB IQHA for Windows

Приложение для мониторинга устройств **IQHA Smart Devices**.

Текущая версия — **1.2.0** (сборка `1.2.0+19`).

## Установка

1. Откройте [последний релиз](https://github.com/Allkorolev/hub.iqha-win-app/releases/latest).
2. Скачайте `hub-iqha-windows-x64.zip` из раздела Assets.
3. Распакуйте весь архив в отдельную папку и запустите `hub_iqha.exe`.
4. В «Настройки → API Ключ» сохраните ключ для доступа к вашим устройствам.

Все DLL и папка `data` должны оставаться рядом с EXE. Удалять или переносить
отдельно эти файлы не нужно.

Рядом с архивом публикуется файл `hub-iqha-windows-x64.zip.sha256` для проверки
загрузки.

## Что нового в 1.2.0

- **Температурная карта** — новый раздел сразу под «Дашборд»: почасовая матрица
  температуры «даты × часы» по данным станции.
- Фильтры станции, периода «30 дней / 90 дней / Год» и диапазона дат с календарём.
- Сводка: минимум, средняя и максимум с датами экстремумов, число суток с данными,
  график среднесуточной температуры и таблица «По месяцам».
- График и ячейки матрицы используют единую температурную шкалу; пропуски не
  интерполируются.
- Колокольчик уведомлений и меню «⋮» с обновлением данных и выбором темы.
- Светлая тема стала контрастнее; тёмная тема сохранена.

## Что нового в 1.1.0

- **Дашборд** — карточки датчиков с разных станций на одной странице. Если на
  дашборде есть хотя бы один датчик, приложение открывается на нём.
- Комплексные карточки «Ветер», «Радиация», «Частицы в воздухе», «Осадки» и
  «Углекислый газ» доступны и на дашборде.
- Ширины карточек **25 / 33 / 50 / 75 / 100 %** с совмещением в одной строке.
- API-ключ в файле резервной копии хранится в зашифрованном виде; сохранённый
  ключ нельзя посмотреть в интерфейсе.
- Исправлено отображение карточек при переключении на тёмную тему.

## Обновления

Откройте «Настройки → О программе → Проверить обновления». Если доступна новая
версия, нажмите «Обновить». Приложение загрузит пакет, проверит его и
перезапустится. API-ключ и пользовательские настройки сохраняются.
