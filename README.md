# HUB IQHA for Windows

Приложение для мониторинга устройств **IQHA Smart Devices**.

## Установка

1. Откройте [последний релиз](https://github.com/Allkorolev/hub.iqha-win-app/releases/latest).
2. Скачайте `hub-iqha-windows-x64.zip` из раздела Assets.
3. Распакуйте весь архив в отдельную папку и запустите `hub_iqha.exe`.
4. В «Настройки → API Ключ» сохраните ключ для доступа к вашим устройствам.

Все DLL и папка `data` должны оставаться рядом с EXE. Удалять или переносить
отдельно эти файлы не нужно.

## Обновления

Откройте «Настройки → О программе → Проверить обновления». Если доступна новая
версия, нажмите «Обновить». Приложение загрузит пакет, проверит его и
перезапустится. API-ключ и пользовательские настройки сохраняются.
